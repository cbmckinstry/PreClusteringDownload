# Pre-Clustering

The Pre-Clustering calculator as a desktop app for macOS, Windows and Linux. Everything runs on your computer: no
internet connection, no account and nothing else to install.

## Download

Get **`Pre-Clustering-<version>.zip`** from the [latest release](../../releases/latest) and unzip it. Open the
folder for your system and double-click the app.

```
Pre-Clustering-<version>/
  How to install.txt
  Mac (Apple Silicon)/  Pre-Clustering.app      M1 and newer
  Mac (Intel)/          Pre-Clustering.app      older Macs
  Windows/              Pre-Clustering.exe
  Linux/                Pre-Clustering
```

On Mac you can move the app to **Applications**. On Windows the app unpacks itself each time it starts, so it
takes a few seconds to open.

## First launch

The app is not signed with a paid developer certificate, so your system asks once.
- **Mac:** right-click the app, choose **Open**, then **Open** again.
- **Windows:** on "Windows protected your PC", choose **More info**, then **Run anyway**.

## Updating

Download the newest release and replace the app with it. Saved results are kept outside the app, so they survive
updates:
- Mac: `~/Library/Application Support/Pre-Clustering`
- Windows: `%APPDATA%\Pre-Clustering`
- Linux: `~/.local/share/Pre-Clustering`
